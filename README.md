# Vedic APT Repository

> **Status: Not yet available.** This repository contains planning notes only; it does not publish an APT package feed. Do not add it as an `apt` source.

For current installation options, see the [Vedic download page](https://vedic-lang.github.io/download/) or the [latest GitHub release](https://github.com/vedic-lang/vedic/releases/latest).

## Planned work

Before advertising APT support, the release process needs to build Debian packages, sign repository metadata, publish the feed over HTTPS, and verify installation on supported Debian and Ubuntu versions. Until those steps are automated and exercised, APT installation is not supported.
